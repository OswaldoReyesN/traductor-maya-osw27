# 500 palabras comunes — Español · Inglés · Maya yucateco

> **Nota importante:** El maya (columnas *Maya*, *Explicación en maya* y *Ejemplo en maya*) sigue en lo posible la ortografía normativa del maya yucateco (alfabeto de 1984, con tonos y vocales largas: *áa*, *aa*, glotal *'*). Las palabras base son de uso común, pero las explicaciones y frases en maya son una **propuesta de borrador**: deben revisarse con una persona hablante o un especialista antes de publicarse en Xíimbal T'aan. Hay variación entre comunidades (por ejemplo, *taata* / *yuum*, *ja'as* para plátano o mamey).

## Notas para la revisión

- **Clasificadores numerales:** se usa *túul* para seres vivos (*jun túul peek'*) y *p'éel* para cosas (*jun p'éel naj*); *kúul* para plantas (*jun kúul che'*).
- **Posesivos ante vocal:** *in / a / u* cambian a *inw- / aw- / uy-* (por ejemplo, *in wotoch*, *a wich*, *u yotoch*).
- **Préstamos:** algunas palabras (*kaape*, *asukar*, *semaana*, *kebóoya*, *limóon*) son préstamos del español usados en el habla cotidiana; conviene decidir si el diccionario las incluye o marca como tales.
- **Entradas para verificar con hablantes:** 71, 83, 124, 125, 216–219, 221, 233, 268, 279, 284, 287, 311, 336, 341, 353, 363, 364, 405, 406, 446.
